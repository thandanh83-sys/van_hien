# (Standard Library) của Python. Dự án này KHÔNG CẦN BẤT KỲ THƯ VIỆN BÊN THỨ BA NÀO.
# 
# Lợi ích: GitHub Actions chạy cực nhanh, bảo mật tuyệt đối, 
# không bao giờ gặp lỗi "Dependency Hell" (xung đột phiên bản).
#
# Các thư viện chuẩn đang được sử dụng ngầm trong code:
# - os       : Tương tác hệ điều hành (lấy đường dẫn, tạo thư mục).
# - sys      : Tương tác hệ thống (thoát chương trình khi có lỗi).
# - json     : Đọc/ghi file JSON (lõi của toàn bộ hệ thống dữ liệu).
# - pathlib  : Xử lý đường dẫn file/thư mục (hiện đại hơn os.path).
# - re       : Xử lý biểu thức chính quy (dùng trong AI và Tìm kiếm).

# PHẦN 3: ⚠️ CẨM NANG BẢO TRÌ (MAINTENANCE NOTES) - ĐỌC KỸ TRƯỚC KHI SỬA
# =====================================================================
# Dưới đây là 8 "Nguyên tắc vàng" được đúc kết từ những lần sửa code bị lỗi.
# Tuân thủ nghiêm ngặt để không bao giờ gặp lại cảnh "trắng trang" hay mất hiệu ứng.

# ---------------------------------------------------------------------
# [QUY TẮC 1] SỬA GIAO DIỆN (HTML/CSS/JS) -> PHẢI TĂNG VERSION TRONG sw.js
# ---------------------------------------------------------------------
# Vấn đề: Service Worker giữ file cũ trong ổ cứng người dùng. Sửa code mà không 
# đổi version thì họ không thấy code mới (gây lỗi trắng trang, mất layout).
# Cách làm: Mở file sw.js, tìm dòng: `const CACHE_VERSION = 'v1.0.0';`
# Đổi thành: `const CACHE_VERSION = 'v1.0.1';` (hoặc bất kỳ số nào mới hơn).
# Khi Test: F12 -> Application -> Service Workers -> Tích "Update on reload" -> Unregister -> Ctrl + F5.

# ---------------------------------------------------------------------
# [QUY TẮC 2] SỬA DỮ LIỆU TÁC PHẨM/TÁC GIẢ -> KHÔNG SỬA TAY FILE INDEX
# ---------------------------------------------------------------------
# Vấn đề: Sửa tay hàng ngàn file JSON sẽ dẫn đến sai lệch ID, hỏng cấu trúc.
# Cách làm: Tạo file `data-tac-pham-master.json` hoặc `data-tac-gia-master.json`.
# Push lên GitHub -> Bot tự động tách file, cập nhật Index và dọn dẹp.
# Nhớ chạy `python tools/validate_data.py` để kiểm tra tính toàn vẹn trước khi Deploy.

# ---------------------------------------------------------------------
# [QUY TẮC 3] HIỆU ỨNG NƯỚC VÀ SƯƠNG -> BẮT BUỘC DÙNG position: fixed & z-index: 1
# ---------------------------------------------------------------------
# Vấn đề: Thẻ <canvas> và <div class="dewdrop-container"> nếu không set position
# sẽ chiếm một khoảng trống khổng lồ (768x1024px), đẩy toàn bộ nội dung xuống dưới.
# Nếu set z-index: -1, chúng sẽ bị chìm dưới nền và biến mất.
# Cách làm: Trong css/base.css, luôn đảm bảo:
#   #water-canvas, .dewdrop-container { position: fixed; z-index: 1; pointer-events: none; }

# ---------------------------------------------------------------------
# [QUY TẮC 4] LỖI TRẮNG TRANG KHI DÙNG ES6 MODULES (IMPORT/EXPORT)
# ---------------------------------------------------------------------
# Vấn đề: Lỗi "does not provide an export named..." hoặc "Failed to fetch dynamically imported module".
# Cách làm: 
# - Đảm bảo mọi hàm cần dùng ở file khác đều có chữ `export` ở file gốc.
# - Tên hàm khi import phải viết HOA/thường giống hệt file gốc.
# - File gốc phải gọi đúng đường dẫn tương đối (./utils.js, ./network/mother.js).

# ---------------------------------------------------------------------
# [QUY TẮC 5] LỖI LAYOUT KHOẢNG TRẮNG ĐẦU TRANG (MIN-HEIGHT)
# ---------------------------------------------------------------------
# Vấn đề: Nội dung bị đẩy xuống dưới, phải lướt lên mới thấy.
# Cách làm: Tuyệt đối không dùng `min-height: 100vh` cho các thẻ `.view` hoặc `.hero`.
# Chỉ dùng `min-height: auto` hoặc căn chỉnh bằng `padding-top` của `.container`.

# ---------------------------------------------------------------------
# [QUY TẮC 6] SỬA TỪ ĐIỂN (data-tu-dien.json) -> TRÁNH BẮT NHẦM TỪ
# ---------------------------------------------------------------------
# Vấn đề: Tooltip bắt nhầm từ trong câu (VD: "nước" trong "yêu nước").
# Cách làm: Không thêm các từ quá phổ biến vào mục "symbols".
# Nếu thêm, phải kiểm tra lại hàm `findSymbols()` trong `js/render.js` 
# để đảm bảo Regex ranh giới từ (word boundary) hoạt động chính xác.

# ---------------------------------------------------------------------
# [QUY TẮC 7] TỦ SÁCH OFFLINE (OFFLINE LIBRARY)
# ---------------------------------------------------------------------
# Vấn đề: Logic tải offline nằm ở 2 nơi, nếu sửa bên này quên bên kia sẽ lỗi.
# Cách làm: Nếu sửa logic tải trong `js/offline.js`, phải kiểm tra lại 
# sự kiện `DOWNLOAD_BATCH` trong file `sw.js` để chúng khớp lệnh (postMessage).

# ---------------------------------------------------------------------
# [QUY TẮC 8] MẠNG LƯỚI TRI THỨC (NETWORK LAYER) - ĐỒNG BỘ MANIFEST
# ---------------------------------------------------------------------
# Vấn đề: Máy Mẹ (mother.js) đọc file `data/manifests/index.json` để tìm đường.
# Nếu bạn thêm/xóa Node (Máy Con) mà không sửa file index này, hệ thống sẽ báo lỗi Fallback.
# Cách làm: Mỗi khi thêm một file `node-xxx.json` mới, BẮT BUỘC phải khai báo
# ID của nó vào mảng `nodes` và bảng `routing` trong file `data/manifests/index.json`.
